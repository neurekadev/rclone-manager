## [1.0.0] - 2026-08-28

### Added

- Add an environment-configured rclone supervisor with multi-platform container images, verified runtime downloads, persistent state, stale FUSE mount repair, signal forwarding, and automatic restart handling.
- Add opt-out error reporting and anonymous lifecycle analytics with a persistent installation identifier and a built-in delivery check.
